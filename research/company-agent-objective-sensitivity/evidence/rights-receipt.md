# Data and artifact rights receipt

Date: 2026-07-23

## Included in this V0

- Source code, schemas, tests, synthetic states, synthetic episodes, prose, and
  figures are newly authored for this project.
- No Ralphthon participant, partner, customer, reviewer, email, Slack, call,
  contract, proposal, or private company record is included.
- Internal Deep Thought and Environment Foundry files were used as read-only
  design context and are not redistributed in this package.
- Ralphthon ICML code was inspected for reusable workflow structure but no result
  artifact or private dataset was copied.

## Public prior work

Primary sources are linked and summarized under research-use citation. No external
benchmark dataset or repository code is vendored. CoffeeBench is citation-only in
V0 and remains excluded from implementation until its exact artifact license,
derivative rights, retention terms, and compute cost are recorded.

## Publication decision

The newly authored synthetic V0 can be reviewed locally. Redistribution of the
whole directory still inherits the surrounding repository's license and must be
checked at release time. Any future public or private data source requires a new
field-level receipt covering access, modification, redistribution, commercial
use, derivatives, retention, revocation, and deletion propagation.
