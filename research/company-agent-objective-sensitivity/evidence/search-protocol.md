# Prior-art search protocol

Status: reproducible scoping search, not a systematic review
Search date: 2026-07-23
Cutoff: sources available through the search date

## Scope

Primary papers, official repositories/datasets, and official venue pages were
searched for MORL/CMDP, reward misspecification, specification gaming, inverse
reward design, scalable oversight, goal misgeneralization, power seeking,
long-horizon tool agents, enterprise/business simulators, process compliance,
delayed outcomes, and experiments varying objectives in a fixed environment.

## Query families

- `"multi objective reinforcement learning" Pareto preference-conditioned policy`
- `"constrained Markov decision process" reinforcement learning`
- `"reward misspecification" specification gaming reward tampering`
- `"goal misgeneralization" objective robustness agent benchmark`
- `"enterprise agent benchmark" long-horizon business simulator`
- `"same environment" reward objective LLM agent behavior`
- `"KPI pressure" business agent benchmark`
- `"process reward" tool trajectory delayed outcome benchmark`

Search results were snowballed through references and official project/repository
pages. Secondary summaries were used only to locate primary sources, not as core
evidence.

## Inclusion

- Directly formalizes changing objectives/constraints or proxy failure; or
- evaluates tool-using agents on enterprise, long-horizon, compliance, process,
  delayed, or harmful-action outcomes; or
- is a closest same-environment objective intervention.

## Exclusion and limitations

Blog-only claims without a primary artifact, generic single-turn business QA, and
unverifiable leaderboard aggregations were excluded. This search did not query
every bibliographic database, use dual independent screening, or establish
publication priority. All negative/absence statements are hypotheses for a second
independent search.
